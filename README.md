## 제출 방법

```bash
git clone https://github.com/ai-insight-cote/intermediate-2026.git
cd intermediate-2026

git switch -c week01-본인이름     # 브랜치 생성
# week01/ 안에 풀이 파일 작성
git add . && git commit -m "week01: 큰 수의 법칙"
git push -u origin week01-본인이름
```

푸시 후 GitHub에서 **Pull Request**를 올려주세요.

> `main` 브랜치는 보호되어 있어 직접 푸시가 불가능합니다. 반드시 브랜치를 만들어 PR로 제출해 주세요.
> 병합된 브랜치는 자동으로 삭제됩니다.
